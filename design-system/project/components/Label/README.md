# Label

A bracketed mono coordinate, `[ LIKE THIS ]`, used as an eyebrow, a caption or a status.

**Props**: `tone` (`muted` default, `blue`, `ink`), `children` (two to four words).

- Labels name or locate things. They are never sentences and never above 11px.
- `muted` (ink-3) on bg and bg-2 only. `blue` marks the live or chosen thing, once per section.
