# Scoper

Four questions and one note that turn into a brief: what we would suggest first, how we would work, and the next step.

**Props**: `initial` (pre-selected answers, `{ kind, stage, team, when }`), `email` (shown as text, default hello@adamass.se).

- It sits at the end of the home page as "Start a project" and on its own at /start.
- The suggestions are a starting point for a conversation, not a quote. No prices, no promised durations.
- The visitor copies the brief and sends it themselves; the page never claims a message was sent.
- The recommendation text is a draft until the partners sign it off.
