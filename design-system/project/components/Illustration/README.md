# Illustration

The five line drawings, one per service, drawn in tokens so they follow the theme.

**Props**: `kind` (`iso` | `schematic` | `contour` | `stack` | `globe`), `plate` (default `true`: sits on a `bg-2` plate with `radius-lg`), `title` (gives it an accessible name; omit when decorative).

How they are drawn:
- Three line tiers. `art` for outlines, `art-2` dashed for guides and minor contours, `art-ink` for solids and anchors.
- Exactly one blue element per drawing: the path that worked, the finding, the primary route.
- The small black chip with two bars is Adamass, wherever it appears.
- Registration crosses sit in the four corners of every plate.
- No text inside drawings, no gradients, no shadows, no people.

The SVG files in the Infographics asset group are light-only exports of the same drawings for decks and documents. On the web, always use this component.
