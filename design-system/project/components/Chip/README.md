# Chip

A toggle for choosing one answer from a short set; selected chips fill blue.

**Props**: `selected` (boolean), `onClick`, `children` (the answer, in the visitor's words).

- Use in the Scoper and in filters on the Work page.
- Unselected chips have a `line-control` border so they pass 3:1 as controls.
- Write options as answers a person would give ("Our own engineers"), not as categories ("In-house").
