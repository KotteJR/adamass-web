# Hero

The opening section: a calm landscape photograph, the construction frame, a two-tone display headline and the product window overlapping the bottom edge.

**Props**: `image`, `imageDark` (the same scene at blue hour), `label`, `lead`, `tail` (blue), `body`, `actions` (`[{ label, href, variant }]`, first is `ink`, second `glass`), `children` (usually a `ProductWindow`).

- The photograph is sky first: headline over empty sky, horizon low, products over the rocks.
- One hero per site. No video, no gradient overlays beyond the fade into `bg`.
- Keep the body to two lines on desktop.
