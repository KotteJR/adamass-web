# Statement

An editorial text block: a two-tone headline on the left, two columns of copy on the right, each column ending on one sentence in `ink`.

**Props**: `lead`, `tail`, `columns` (`[{ text, emphasis }]`, two), `actions` (`[{ label, href, variant }]`).

- One per page, right after the client logos. It carries the position; everything after it is evidence.
- Each column is 50 to 70 words. The `emphasis` sentence is the one a skimmer should keep.
- Generous padding: `space-11` above and below on desktop.
