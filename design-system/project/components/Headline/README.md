# Headline

A two-line headline: the first line in `ink`, the tail recedes in `ink-4` or signals in `blue-text`.

**Props**: `lead`, `tail` (optional second line), `tone` (`gray` default, `blue`), `size` (`h2` default = the `heading` style, or `display`), `as` (`h1` | `h2` | `h3`).

- Gray tails for section headlines: the first line states, the tail qualifies.
- The blue tail is for the hero only, once per site.
- Keep both lines under about 28 characters so the break lands where you wrote it.
